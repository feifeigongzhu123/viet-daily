隐私政策

最后更新：2026 年 11 月 21 日 · 适用版本：1.2.2

越词通（以下简称“本应用”）是一款越南语背单词工具，由安得半日闲开发。我们尽量少收集数据：本应用不需要注册或登录，学习进度只保存在你自己的设备上。

1. 我们收集哪些信息

我们不收集、不上传你的学习记录。每日计划、已学单词、复习时间、学习天数、显示设置等数据，均保存在浏览器的本地存储（localStorage）中。卸载应用、清除站点数据或使用应用内的“清除学习记录”，即可删除这些数据。

本应用没有账号系统，没有广告 SDK，没有统计分析 SDK，也不会读取通讯录、位置、相机、麦克风或相册。

2. 网络请求与第三方服务

  • 站点托管：网页版由 GitHub Pages 提供。访问时 GitHub 可能按照其隐私政策记录常规服务器日志（如 IP 地址、浏览器类型），用于安全与稳定运行。
  • 离线音频：单词、例句和字母音音频已预先生成并随应用缓存，播放时不需要上传任何内容。音频制作阶段使用了 Microsoft Edge 神经网络语音服务，该过程不涉及用户数据。
  • 系统语音兜底：如果某个音频文件缺失，应用可能调用设备自带的语音合成功能。该功能由你的操作系统或浏览器提供，是否联网由系统决定；本应用不会把学习记录发送给语音服务。
  • 词表与例句：部分词表和例句来自 Tatoeba、dict.minhqnd.com 等公开资源，署名与许可见应用内“关于”及仓库中的 THIRD_PARTY_NOTICES.md。

3. 数据安全与保留

学习数据仅存在本机，受浏览器同源策略保护。我们无法远程查看、导出或恢复你的学习记录。更换设备、更换浏览器或清除浏览器数据后，记录不会自动迁移。

4. 儿童隐私

本应用面向一般语言学习者，不专门面向 13 岁以下儿童，也不会主动收集儿童个人信息。

5. 你的选择

  • 在“我的”页面点击“清除学习记录”，可删除本机全部学习进度。
  • 在浏览器设置中清除该站点的数据，可删除本地缓存与学习记录。
  • 不使用本应用即不产生任何学习数据。

6. 政策更新

如果本政策发生重大变化，我们会在应用内或项目页面更新说明，并修改上方的“最后更新”日期。继续使用即表示你接受更新后的政策。

7. 联系方式

如有隐私相关问题，可在项目页面提交 issue：github.com/feifeigongzhu123/viet-daily/issues。
