# Google Play 数据安全表单参考答案

> 依据当前版本 1.2.1 的实现：学习进度保存在浏览器 / WebView 的 localStorage；无账号、无广告、无统计分析、无自建服务器接口。

## 概览

- 应用是否收集或共享任何必填用户数据类型：**否**
- 应用是否处理用户数据：**是，但仅在设备本地处理，不传输**
- 数据是否加密传输：**不适用**（没有向开发者服务器传输数据）
- 是否提供数据删除方式：**是**（应用内“我的 → 清除学习记录”）
- 是否遵循“家庭政策”：**否**（目标受众不含儿童）

## 数据类型逐项

| 类型 | 收集 | 共享 | 说明 |
| --- | --- | --- | --- |
| 位置 | 否 | 否 | 不请求定位权限 |
| 个人信息（姓名、邮箱、电话等） | 否 | 否 | 无账号、无表单 |
| 财务信息 | 否 | 否 | 无付费功能 |
| 健康与健身 | 否 | 否 | — |
| 消息 | 否 | 否 | — |
| 照片和视频 | 否 | 否 | 不访问相册/相机 |
| 音频文件 | 否 | 否 | 不录音；播放的是内置音频 |
| 文件和文档 | 否 | 否 | — |
| 日历 | 否 | 否 | — |
| 通讯录 | 否 | 否 | — |
| 应用活动（页面浏览、点击等） | 否 | 否 | 无埋点、无分析 SDK |
| 网页浏览 | 否 | 否 | — |
| 应用内搜索记录 | 否 | 否 | 搜索只在本地内存中进行，不存储、不上传 |
| 已安装应用列表 | 否 | 否 | — |
| 设备或其他 ID | 否 | 否 | 不读取广告 ID 或设备标识 |
| 崩溃日志 | 否 | 否 | 未集成崩溃收集 SDK |

## 本地保存的数据

以下数据保存在用户设备的 localStorage，不会发送给开发者：

- 每日学习计划与完成状态
- 单词学习阶段、复习日期、连续学习天数
- 显示设置（每日词数、播放速度、界面尺寸、是否显示谐音）

用户可通过应用内“清除学习记录”删除，或在系统设置中清除应用/浏览器数据。

## 第三方说明

- **GitHub Pages**：仅用于托管静态网页；服务器日志由 GitHub 按其隐私政策处理，开发者不接触这些日志中的个人数据。
- **Microsoft Edge 神经网络语音**：仅在制作音频时使用，运行时不上传用户数据；应用内音频已预生成并离线缓存。
- **浏览器/系统语音合成**：仅在某条音频缺失时作为兜底；由用户设备系统处理。
- **Tatoeba、dict.minhqnd.com 等**：提供词表或例句内容，不接收用户数据。

## 权限说明（生成 APK 后核对）

TWA/Bubblewrap 默认只需要网络权限（`INTERNET`），用于首次加载页面和更新缓存。若打包工具额外加入定位、相机、麦克风、通讯录等权限，应在提交前移除，并在本表中改为“是”并说明用途。
